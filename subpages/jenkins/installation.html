New Instance of WAR

Just two lines to get Jenkins up and running

# Run in Command Prompt with administrator privileges
# Prepare directory for Jenkins
PS C:\Users\TSUPP> set JENKINS_HOME=C:\your\path\jenkins
# Use Java JDK 17 or 21 (depending on Jenkins requirements)
# Run the downloaded jenkins.war file on a custom port
PS C:\your\path\jenkins> java -jar jenkins.war --httpPort=8989
