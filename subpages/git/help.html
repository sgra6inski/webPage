Where to use
  • ❖ GIT

The time machine and version control.

Tool lets you track code changes and manage project history across distributed teams, making collaboration and release management fast and reliable.

GitHub, GitLab, Bitbucket, Codeberg, and Gitea are platforms where you can host Git repositories and run Git commands.

Useful when you want to:

  • Track every change made to your codebase
  • Collaborate on features without overwriting work
  • Test new ideas safely in isolated branches
  • Roll back to previous versions in seconds

Everything is stored in a lightweight local repository with full offline history.
