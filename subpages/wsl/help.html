Where to use
  • ❖ WSL

No, you don't need it at all... but it can be useful for

  • Docker tools
  • A second system
  • Another custom system :)

You can manage the subsystems at the Windows level while working on a single machine, and it handles multiple tasks quite quickly.

In scenarios where you need:

  • To handle multiple tasks
  • To reproduce issues
  • To prepare a clean, untouched system
  • To conduct investigations

All of this can be done on a single machine. You can run as many instances as your resources allow.
