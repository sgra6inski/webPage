Commands example
  • ❖ DOCKER

Let's fire up container...

1. Example with port mapping (runs in the background):

sudo docker run --name nameOfYourContainer \
  -p 8080:8080 -p 8082:8082 -p 8443:8443 \
  --user root:root \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v tool-volume:/mnt/companyProduct \
  -v /mnt/c/Users/yourUser/dtp_data:/usr/local/companyProduct/data \
  -d dockerHubImage/tool:tag

Breakdown:

  • If your machine does not have the image locally (line 7), Docker will download it from Docker Hub first.
  • --name nameOfYourContainer – sets a custom name for your container.
  • -p 8080:8080 -p 8082:8082 -p 8443:8443 – maps ports between your host machine and the container (host:container).
  • --user root:root – runs the container with root privileges.
  • -v host:container – mounts a volume or bind mount (links a directory or file between your host machine and the container).
  • -d dockerHubImage/tool:tag – runs the container in detached mode (in the background) using a specific image and version tag from Docker Hub.

2. Example using Bash (waits until the user exits):

sudo docker run --name nameOfYourContainer \  
  --user root:root \
  -v tool-volume:/mnt/companyProduct \
  -v /host/path:/container/path \
  -it dockerHubImage/tool:tag /bin/bash

Breakdown:

  • If your machine does not have the image (line 5), it will download the image from Docker Hub first
  • --name nameOfYourContainer – sets a custom name for your container
  • --user root:root – runs the container with root privileges
  • -v host:container – mounts a volume (links a folder or named volume between your machine and the container)
  • -it dockerHubImage/tool:tag /bin/bash – runs the container in interactive mode with a terminal and starts a bash shell (keeps the container running until you type exit)

3. Example copy file from container into host:

sudo docker cp nameOfContainer:/container/path/app.log /host/path/download/
