Chef and a recipe

Actions is the chef doing the work, and the YAML file is the written list of instructions.

Yaml file - publish the webPage: 

# The display name of the workflow shown in the GitHub Actions tab
name: Deploy Static Site to GitHub Pages

# Defines the event that triggers this pipeline
on:
  push:
    # Runs automatically whenever new commits are pushed to the 'main' branch
    branches: ["main"]

# Sets security permissions for the automated token used by this workflow
permissions:
  contents: read   # Allows the runner to read and download your repository's code
  pages: write     # Allows the workflow to deploy files to GitHub Pages
  id-token: write  # Allows generating a secure token to verify the deployment's identity

# Defines the tasks (jobs) that will execute
jobs:
  deploy:
    # Specifies the virtual machine environment (latest Ubuntu Linux)
    runs-on: ubuntu-latest
    
    # Links this job to the 'github-pages' environment and displays the live URL after deployment
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
      
    # Sequential list of tasks to execute on the virtual machine
    steps:
      - name: Checkout code from repository
        uses: actions/checkout@v4

      - name: Package the entire project
        uses: actions/upload-pages-artifact@v3
        with:
          # Specifies the folder to upload; '.' means the entire root directory
          path: '.'

      - name: Deploy to GitHub Pages (HTTPS)
        # Assigns an ID so the 'environment' block above can reference its output URL
        id: deployment
        uses: actions/deploy-pages@v4
