Runner
  • ❖ GITHUB

Personal runner, no shoes needed

GitHub runner is a virtual server that executes your automated tasks whenever you update your code.

Follow the instruction:
1. Your Repository -> Settings (top tab) -> Actions (left sidebar) -> Runners
2. Press "New self-hosted runner" follow the instruction on GitHub to install the tool.
3. Optional suggestion. During the process of installation do not install as a service.

  • Visibility: You will only see the Settings tab if you are the owner or an administrator of that repository.
  • Organization level: If you are managing runners for a whole team or company, go to Your Organization -> Settings -> Actions -> Runners instead.
