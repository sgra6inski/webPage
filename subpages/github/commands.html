Commands
  • ❖ GIT

Easy to forget, easy to recall

A couple of useful commands:

# Download (clone) an existing repository from a remote server to your computer
git clone git@github.com:user/project.git

# Initialize a new local Git repository
git init

# Link your local repository to a remote server (e.g., GitHub)
git remote add origin git@github.com:user/project.git

# Check the current status of modified and untracked files
git status

# Stage all changes for the next commit
git add .

# Save staged changes to history with a descriptive message
git commit -m "your comment"

# Rename the current default branch to "main"
git branch -M main

# Push your commits to the remote repository for the first time
git push -u origin main

# Remove all cached files so .gitignore rules apply cleanly (run "git add ." afterward)
git rm -r --cached .

# List all local and remote branches
git branch -a

# Show who last modified each line of a specific file and when
git blame yourFile

# Compare differences in a specific file between two branches
git diff firstBranch mainBranch yourFile

# Switch to another branch (or restore working tree files)
git checkout branchName

# Fetch and merge the latest changes from the remote repository
git pull

# Rename the current local branch, push the new name to the server, and delete the old remote branch
git branch -m newNameBranch
git push -u origin newNameBranch
git push origin --delete old_NameBranch

# Create a new branch and switch to it immediately
git checkout -b newFeatureBranch

# Display a compact, visual commit history graph
git log --oneline --graph --all

# Temporarily save uncommitted changes without committing them (and restore them later with "git stash pop")
git stash

# Merge changes from another branch into your current branch
git merge featureBranch

# Safely undo a specific commit by creating a new commit that reverses its changes
git revert commitHash

Breakdown:

You only need the Git software installed on your computer and a terminal application to type and execute the commands. For remote collaboration, you will also need a free account on a hosting platform like GitHub and an SSH key or access token.
