What is GitHub?

GitHub is a cloud-based hosting platform for your Git repositories. While Git is the tool that tracks changes locally on your computer, GitHub acts as a central online hub where you can store your code, back it up, and collaborate with developers from anywhere in the world.

Alongside alternatives like GitLab, Bitbucket, Codeberg, and Gitea, it adds a user-friendly web interface and powerful project management features on top of standard Git commands.

GitHub is essential when you want to:

  • Host your code in the cloud as a secure backup and portfolio
  • Review and merge code changes cleanly using Pull Requests
  • Track bugs, feature requests, and tasks with built-in Issues
  • Automate testing and deployments using GitHub Actions (CI/CD) - Runners

Your local repository stays synced with the remote server, giving your team a single source of truth for every project.
