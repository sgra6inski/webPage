Repositories
  • ❖ GITHUB

Not only files

An online project folder that stores your code, files, and their complete change history

  • Version control. It saves every edit you make so you can easily undo mistakes or revert to older versions.
  • Collaboration. Multiple people can work on the same project simultaneously without overwriting each other's work.
  • Access control. You can make it public (visible to everyone) or private (restricted to you and invited collaborators)
